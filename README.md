📊 Examination Center Monitoring System
📌 Overview

The Examination Center Monitoring System is a data analytics-based project designed to improve transparency, efficiency, and security in examination centers. It integrates operational data such as attendance records, surveillance logs, system performance metrics, and incident reports to generate meaningful insights using a Power BI dashboard.

The system helps administrators monitor exam activities, detect irregularities, and make data-driven decisions efficiently.

🎯 Objective
Improve monitoring of examination centers
Reduce manual reporting errors
Provide real-time insights using dashboards
Enhance decision-making through data visualization
Detect anomalies and operational issues efficiently
